WME - RIGHTCLICK FUNCTIONS — CHROME EXTENSION

1. Clone https://github.com/Snapmatics/wme-scripts with GitHub Desktop.
2. Put this folder at: <repository>/WME-RightClick-Extension/
3. Open chrome://extensions and enable Developer mode.
4. Click Load unpacked and select WME-RightClick-Extension.
5. Disable the Tampermonkey version.
6. Reload WME production and beta tabs.

After every GitHub Desktop pull or code change:
- click Reload on the extension card in chrome://extensions;
- reload WME.
