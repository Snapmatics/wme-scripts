FRIENDS ONLINE/OFFLINE — FIRESTORE RULES UPDATE

The new presence indicator uses a separate realtimeSignals/presence-{WME-ID}
document so it cannot overwrite friend-request or pin notifications.

1. Open Firebase Console.
2. Select project: wme-rightclick-function
3. Open Firestore Database > Rules.
4. Replace the deployed rules with firestore.rules from this ZIP.
5. Click Publish.
6. Replace the extension files on every computer.
7. Reload the extension and hard-refresh WME.

Both friends need the updated userscript for live Online/Offline heartbeats.
Without the new rules, the visual redesign works but users remain Offline.
