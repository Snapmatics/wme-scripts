Add this inside your existing Firestore `match /databases/{database}/documents` block, then publish the rules:

match /realtimeSignals/{signalId} {
  allow read: if request.auth != null;
  allow create, update: if request.auth != null
    && request.resource.data.keys().hasOnly([
      'targetUid',
      'eventType',
      'nonce',
      'updatedAt'
    ])
    && request.resource.data.targetUid is string
    && request.resource.data.eventType is string
    && request.resource.data.nonce is string
    && request.resource.data.updatedAt is timestamp;
  allow delete: if false;
}
